Fundamentos da Web

Página Estática

Uma página estática é uma página que o conteúdo normalmente é enviado pelo servido para o navegador da mesma forma como foi criado. Oconteúdo não é gerado de acordo com informações do usuário ou consultar a um banco de dados

Exemplo: Uma página institucional apresentando informações de uma empresa.

Página Dinãmica

Uma página dinãmica é uma página que o conteúdo pode ser criado ou alterado de acordo com dados, usuários, informações de um banco de dados ou regras da aplicação

Exemplo: a página de perfil de um usuário em uma rede social

Fluxo de uma requisição

  1. O usuário acessa um endereço pelo navegador
  2. O navegador envia uma requisição HTTP para o servidor
  3. Caso necessário. o servidor consulta um banco de dados
  4. O servidor prepara uma resposta
  5. A resposta é enviada de volta para o navegador
  6. O navegador interpreta os arquivos recebidos e apresenta a página para o usuário
